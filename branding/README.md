# Branding Assets

This directory holds stable GoodQ4All brand assets that are safe for docs,
release pages, and public presentation work.

## Tracked Assets

- `goodbrand.svg`
- `favicon.ico`
- `site.webmanifest`

## Local Generated Exports

Generated HTML exports under `branding/*.html` are local working artifacts.
They may be useful for design review, but they are ignored by default and
should only be promoted when a specific docs, demo, or release surface owns
them.

Use `samples/assets/` or a committed docs page for final public-facing media.
