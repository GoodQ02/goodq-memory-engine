                         ENVIRONMENT ISOLATION
═════════════════════════════════════════════════════════════════════════

Each step runs in isolated conda environment:

    goodq_zenml              → Main pipeline coordinator
    goodq_audio_diarize      → Audio processing
    goodq_text_embed         → Text embeddings
    goodq_video_scene_detect → Video analysis
    [other_envs]             → Specialized processing

Isolation flags:
    • PYTHONNOUSERSITE=1
    • PIP_NO_CACHE_DIR=1
    • --no-user --isolated --no-cache-dir
