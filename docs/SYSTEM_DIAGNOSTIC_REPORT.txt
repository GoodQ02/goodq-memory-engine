========================================
WHY THIS HAPPENED
========================================

CONDA PATH WAS TEMPORARY:
  • Conda installer added paths to current session only
  • OR paths were added to System PATH temporarily
  • Windows requires User/System registry PATH for .BAT files
  • PowerShell sessions can have different PATH than CMD

WINDOWS STORE INTERFERENCE:
  • Windows 10/11 includes python.exe stub
  • Located in: %LOCALAPPDATA%\Microsoft\WindowsApps
  • This folder is in PATH by default
  • Redirects to Store installer page
  • Blocks your real Python installation

THE CONFUSION:
  • Works in PowerShell = PATH is right in that session
  • Fails in .BAT = PATH not in registry
  • Works when using full paths = bypasses PATH entirely
