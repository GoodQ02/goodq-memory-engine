Read [project orientation](PROJECT_ORIENTATION.md), the root operating protocol,
and the canonical contract for the task before changing code.

[Current state](CURRENT_STATE.md) and its JSON/context projections are explicit
public templates. They contain no observed runtime or personal corpus evidence.

configuring your installation; never publish that private capture by default.

Use [first run](../guides/FIRST_RUN.md), [installation](../bootstrap/INSTALL_BOOTSTRAP.md),
and [runtime modes](workflows/LOCAL_DEV_RUNTIME_MODES.md) for operator setup.

source provenance and exclusions. Tests and source publication do not establish
live runtime readiness.
