 🎨 DESIGN PRINCIPLES
───────────────────────────────────────────────────────────────────────

1. Single Source of Truth
   → All paths in one place (configs/paths.py)

2. Separation of Concerns
   → Code (GitHub) | Data (local) | Archive (reference)

3. Environment Isolation
   → Each step in its own conda env with strict isolation

4. Data Flow
   → inbox → processing → databases → completed → exports

5. Logging Strategy
   → Centralized JSONL logs, easy to parse
