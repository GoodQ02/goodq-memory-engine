## Complete User Journey

### 🚀 First-Time Setup
1. Run `LAUNCH_GOODQ.bat`
2. Three windows open automatically (API, Dashboard, Launcher)
3. System status visible immediately

### 📥 Processing Files

**Option A: Automatic (Watchdog)**
1. Run `START_WATCHDOG.bat`
2. Drop files into `import_inbox/`
3. Automatic queue processing
4. Files renamed with `_INGESTED` when complete

**Option B: Manual**
1. Activate conda environment
2. Run CLI command with video path
3. Watch progress in Command Center
