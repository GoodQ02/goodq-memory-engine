# Reference Anchors

Public release artifacts document methodology and aggregate metrics only.

Copyrighted third-party reference anchors are not shipped in the public release.
Private or third-party anchors used during local witness scoring must remain
outside tracked public artifacts unless a separate source/license review clears
them for redistribution.

Runtime scene truth is generated locally from user-provided media. Reference
anchors, when used privately, are audit aids only; they do not override scene
manifests, temporal indexes, or other persisted runtime truth.

Public examples and future debug fixtures must use fictional, owned, synthetic,
or permissively licensed materials.
